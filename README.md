# PCOS Health Tracker

A full-stack web application designed to help users monitor and manage Polycystic Ovary Syndrome (PCOS) related health activities, symptoms, menstrual cycles, hydration, diet, exercise, and overall wellness.

## Live Demo

🌐 Live Project: https://pcos-health-tracker.vercel.app

## Overview

PCOS Health Tracker was developed to provide a centralized platform where users can track important health information related to PCOS and build healthier daily habits. The application helps users monitor symptoms, record health activities, and maintain consistent health tracking over time.

This project was created as a major academic project with a focus on real-world healthcare challenges and user-centered design.

## Features

* User Registration and Login
* Secure Authentication System
* PCOS Symptom Tracking
* Menstrual Cycle Monitoring
* Water Intake Tracking
* Diet Management
* Exercise Tracking
* Personalized Health Dashboard
* Health Record Management
* Responsive User Interface
* Real-Time Data Updates

## Installation

### Clone Repository

```bash
git clone https://github.com/kirankv8641/PCOS-Health-Tracker.git
```

### Navigate to Project Folder

```bash
cd PCOS-Health-Tracker
```

### Install Dependencies

Frontend

```bash
npm install
```

Backend

```bash
npm install
```

### Start Development Server

Frontend

```bash
npm run dev
```

Backend

```bash
npm start
```
